#  Веб-приложение для формирования расписания

Электронная версия процесса составления расписания учебных занятий с использованием цветных карточек на физической доске.

---

##  Описание

Проект представляет собой электронную интерактивную доску для составления расписания учебных занятий. Группы располагаются по горизонтали, дни недели и пары — по вертикали, справа — панель преподавателей и дисциплин. Карточки занятий можно перетаскивать (Drag & Drop), система автоматически проверяет конфликты и поддерживает две учебные недели.

Приложение заменяет физическую доску с цветными карточками, автоматизируя:

- хранение данных о группах, преподавателях и дисциплинах;
- формирование расписания на 1-ю и 2-ю учебные недели;
- проверку конфликтов (преподаватель, группа, кабинет);
- просмотр, сравнение и печать расписания.

---

##  Цель проекта

Разработать веб-приложение, позволяющее ответственному за составление расписания:

- создавать учебные группы;
- создавать список преподавателей;
- создавать список дисциплин;
- связывать преподавателей с несколькими дисциплинами;
- формировать расписание на 1-ю и 2-ю учебные недели;
- размещать занятия в расписании;
- перемещать занятия с помощью Drag & Drop;
- редактировать и удалять занятия;
- обнаруживать конфликты;
- сохранять готовое расписание;
- просматривать, сравнивать и распечатывать расписание.

## 🗄 Структура базы данных

| Таблица | Назначение | Поля |
|---------|-----------|------|
| `groups` | Учебные группы | id, name, speciality, course |
| `teachers` | Преподаватели | id, name, short_name, color |
| `subjects` | Дисциплины | id, name, short_name |
| `teacher_subjects` | Связь M:N | teacher_id, subject_id |
| `lessons` | Занятия | id, group_id, teacher_id, subject_id, classroom_id, day, week1_lesson, week2_lesson, lesson_type |

**Связи:**

- `teacher_subjects` — многие-ко-многим между `teachers` и `subjects`;
- `lessons` — ссылается на `groups`, `teachers`, `subjects`, `classrooms`;
- поля `week1_lesson` и `week2_lesson` — целые числа (1–6) или NULL, что позволяет одной карточкой описать сразу две учебные недели.

**Схема:**

groups ─── lessons ─── teachers
│ │
│ └── teacher_subjects ─── subjects
│
└── classrooms

##  Функционал

### Справочники

- **Группы** — добавление, редактирование, удаление; поля: название, специальность, курс.
- **Преподаватели** — добавление, редактирование, удаление; поля: ФИО, краткое обозначение, цвет из палитры, несколько дисциплин.
- **Дисциплины** — добавление, редактирование, удаление; поля: название, сокращение, преподаватель.
- **Кабинеты** — добавление, номер, тип, вместимость (дополнительно).

### Главный экран

- Таблица расписания: группы в столбцах, дни недели и пары в строках.
- Панель преподавателей и дисциплин справа.
- Крупные карточки занятий с информацией о двух неделях.
- Кнопка «+ Добавить занятие».

### Работа с занятиями

- Добавление через форму и через Drag & Drop.
- Редактирование по клику на карточку.
- Удаление занятия.
- Перемещение карточек между ячейками.

### Проверка конфликтов

- Конфликт преподавателя (занят в одной паре на одной неделе).
- Конфликт группы (два занятия в одной паре).
- Конфликт кабинета (при учёте кабинетов).

### Хранение данных

- SQLite через SQLAlchemy.
- Автоматическое сохранение при каждом изменении.
- Миграции через Flask-Migrate.

### Дополнительно

- Страница сравнения 1-й и 2-й недель (`/compare`).
- Страница печати расписания (`/print`).
- Экспорт в Excel (опционально).

## Индивидуальное задание №23

**Сравнение расписаний двух недель.**

На странице `/compare` отображается:

- **таблица различий** — пары, которые есть только на 1-й неделе, только на 2-й, совпадающие и различающиеся;
- **матрица расписания** — все группы × дни × пары с обеими неделями;
- **цветовая индикация**:
  - 🟢 зелёный — только 1-я неделя;
  - 🔵 голубой — только 2-я неделя;
  - ⚪ серый — совпадает;
  - 🟡 жёлтый — отличается.
